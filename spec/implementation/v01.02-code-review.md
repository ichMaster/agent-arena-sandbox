## Findings

### #1 🔴 `assign_symbol` race → uncaught `IntegrityError` (HIGH) — FIX NOW
**Failure scenario:** two players (or an agent + a human) connect to a brand-new match at nearly the
same instant. Both concurrent `assign_symbol` calls read `taken = {}` before either has committed,
both pick `"X"`, one `commit()` succeeds and the other raises `IntegrityError` **uncaught** —
crashing the second caller's request instead of correctly falling back to `"O"`. This directly
threatens the roadmap's own v04 "two agents connect to one match" headline scenario. The `UNIQUE`
constraint (already in place, #004) correctly *detects* the race — but nothing currently *resolves*
it.
**Fix:** wrap the read-pick-commit sequence in a bounded retry loop: on `IntegrityError`, roll back and
retry with the now-updated taken set (at most `len(_SYMBOLS) + 1` attempts, since there are only two
symbols to contend over).

### #2 🟡 Redundant query in `current_turn` (LOW) — deferred
`current_turn` calls `reconstruct_game` (which loads every `Move` row) and then runs a *second* query
just to count them. Two round trips instead of one at MVP's single-match scale — real but low-value;
homed to v05.01 alongside the roadmap's other resilience/perf polish.

## Fixes applied

Suite after the fix: **62 passed**, deterministic; `mypy --strict` clean (8 source files). No seam
changed — no `architecture.md` edit (§5.2 already documents "otherwise assign the first free symbol
... `UNIQUE(match_id, symbol)` guards against a race"; this fix is exactly that guard's resolution
path, not a new contract).

### ✅ #1 — race-safe `assign_symbol`
`server/repository.py`: the read → pick-free-symbol → commit sequence now runs in a bounded retry
loop; a `commit()` that raises `IntegrityError` triggers a `rollback()` and a retry with a freshly
re-read taken set, up to `len(_SYMBOLS) + 1` attempts. **Test:**
`tests/test_seats.py::test_concurrent_assign_resolves_to_distinct_seats` — two separate sessions call
`assign_symbol` concurrently via `asyncio.gather`; asserts `{"X", "O"}` and no exception.

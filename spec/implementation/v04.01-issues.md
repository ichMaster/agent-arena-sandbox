## v04.01 — Contrasting personas (the theater)

### ARENA-105 — Contrasting personas: refine `aggressive.yml` + add `cautious.yml`

**Description:**
Two persona profiles whose `system_prompt`s produce visibly different tone and play style when
watched head-to-head -- the actual product per game_specification.md §1 ("the theater"). Touches:
`profiles/`.

**What needs to be done:**
- Refine `profiles/aggressive.yml` (Aggressor, already exists from v02.02): keep the swaggering,
  center/fork-seeking tone, but sharpen the taunt style so it reads distinctly against a
  contrasting opponent rather than in isolation. Keep `model_type: "haiku"`; a higher
  `temperature` (already `0.9`) suits the brasher persona.
- Add `profiles/cautious.yml`: a new, contrasting persona -- e.g. a wary, defensive player whose
  banter is measured, cautious, watching for the opponent's traps rather than pushing forks. Lower
  `temperature` than Aggressor's (a steadier, less erratic tone fits the character and gives a real
  tonal + stylistic contrast when the two are watched together). Distinct `name`, its own
  `memory_limit` (doesn't need to match Aggressor's).
- Both `system_prompt`s must stay within the existing move contract (architecture.md §7.3): the
  persona governs `comment`, never how `move` is chosen or validated -- `decide()`'s retry/fallback
  logic (agent/agent.py, unchanged) is what guarantees a legal move regardless of persona flavor.
- No code changes -- this issue is pure profile-tuning content, `agent/profile.py`'s schema and
  loader are already correct and unchanged.

**Dependencies:** None

**Expected result:**
Loading either profile produces a valid `AgentProfile`; reading the two `system_prompt`s side by
side shows a clear tonal and stylistic contrast (aggressive/taunting vs cautious/wary).

**Acceptance criteria:**
- [ ] `profiles/cautious.yml` exists with all required `AgentProfile` fields and a genuinely
      contrasting `system_prompt` (name, tone, and temperature all differ from `aggressive.yml`).
- [ ] `profiles/aggressive.yml`'s tuning is refined for contrast against `cautious.yml` specifically
      (not just standalone flavor).
- [ ] **Unit test:** both profiles load via `AgentProfile.load_from_yaml` and validate (required
      fields present, `temperature`/`memory_limit` in sane ranges) -- no model call.
- [ ] Ties to phase DoD: "running each profile produces visibly different tone and taunting; both
      still emit valid `{move, comment}` every turn" (the second half is already guaranteed by
      `decide()`'s existing retry/fallback contract, unchanged by this issue).

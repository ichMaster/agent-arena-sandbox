> **⟳ Reconciled (2026-07-21):** the aggressive persona's real shipped name is `Ironclaw`, not "Blaze"
> — corrected throughout this issue (see the file intro's reconciliation note for why the name must be
> kept, not renamed).

**Description:** author two personas whose `system_prompt`s produce a real clash of tone and play
style, tuned so the banter lands while both stay within the move contract (§1, §5.2). Touches:
`profiles/aggressive.yml`, `profiles/cautious.yml`, `tests/`.

**What needs to be done:**

  `system_prompt` (center/corner-seeking, double-threat play; short, punchy, playful trash-talk in the

- **`profiles/cautious.yml` (new):** a **wary defender** persona (a distinct name, e.g. "Bastion") —

  and **distinct** (different names, and a lower cautious `temperature` than aggressive); each
  `model_type` drives the real `create_llm_client` (SDK patched — **no paid call**). Persona *quality*
  is judged by the demo, not asserted.

**Dependencies:** None (extends v02.02's `AgentProfile`).

**Expected result:** `AgentProfile.load_from_yaml("profiles/cautious.yml")` and `…/aggressive.yml`
both return valid, visibly different profiles ready for the orchestration script (v04.02).

**Acceptance criteria:**
- [ ] `profiles/aggressive.yml` (refined) + `profiles/cautious.yml` exist, contrasting in name/tone/`temperature`/`memory_limit`.

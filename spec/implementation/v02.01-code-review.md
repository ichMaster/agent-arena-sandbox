## What's solid

- **Structured output is forced, and the enforcement is structural.** An AST test fails on any
  `json.loads`/`load` in the module, so the seam's whole purpose cannot be quietly undone by a later
  edit that hand-parses a reply.
- **The model id is pinned and single-sourced.** A test asserts it equals `claude-haiku-4-5`, that it
  carries no date suffix, and that the literal appears exactly **once** in the module — so the model
  cannot drift or be duplicated into two places that disagree.
- **The key is asserted absent from `repr` and error text**, which is the realistic escape route (§9)
  — a traceback, not a deliberate log line.
- **`agent/` is asserted to import nothing from `server/`** over the AST, keeping it a true external
  client (§2).
- **`AgentResponse.move` is deliberately unconstrained**, with the reason recorded: the server is the
  legality authority, and a second weaker one in the agent would invite trusting it.
- **Every test mocks the vendor.** The SDK is patched at construction; no test can spend quota.

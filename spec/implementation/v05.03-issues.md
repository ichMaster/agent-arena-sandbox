## v05.03 — Polish & docs

### ARENA-OPUS-037 — README + `.env.example` + doc-smoke test

**Description:** write the README that lets a newcomer set up the project and run all three modes from
a clean checkout, add a `.env.example`, and a doc-smoke test that keeps the README honest. Touches:
`README.md`, `.env.example`, `tests/`.

**What needs to be done:**
- `README.md`:
  - **What it is** — the theater: LLM agents (Anthropic Haiku) play Tic-Tac-Toe over WebSockets,
    watched in a browser; Player and Observer roles.
  - **Architecture at a glance** — the three cooperating processes (server / agent / Web UI) + the two
    seams; links to `spec/game_specification.md`, `spec/architecture.md`, `spec/web_ui_specification.md`.
  - **Setup** — Python venv, install (editable + **`[dev]`** — the real extra name), put
    `ANTHROPIC_API_KEY` in `./.env` (the key lives only in the agent process; never sent to/logged by
    the server or UI).
  - **Run** — start the server (`uvicorn server.main:app`), then the **three modes**: (1) human-vs-agent
    (open `/ui` → Host → run `agent/agent.py …`), (2) agent-vs-agent (`./scripts/run_arena.sh` →
    Observe with the printed id), (3) observe (`/ui` → Observe). Use **Observe**, not Join, to watch.
  - **WebSocket protocol summary** — the five server events + the two client actions (point at
    architecture §6 for the contract).
  - **Testing** — `pytest` + `mypy`; the LLM is always mocked → **no paid calls**.
  - **Data & reset** — `./arena.db` (SQLite, gitignored) survives restarts; delete it to reset.
- `.env.example`: `ANTHROPIC_API_KEY=` placeholder (+ a one-line comment) so a newcomer knows the one
  required secret. (Confirm it is **not** gitignored, while `.env` stays ignored.)
- `tests/test_readme.py` (doc-smoke, no execution of live commands): the README references the real
  entry points — `uvicorn server.main:app`, `/ui`, `agent/agent.py`, `profiles/aggressive.yml`,
  `scripts/run_arena.sh`, `ANTHROPIC_API_KEY`, `pytest` — **and** the files it points at actually exist
  (`agent/agent.py`, `scripts/run_arena.sh`, `profiles/aggressive.yml`, `profiles/cautious.yml`,
  `.env.example`); all three run modes are documented; the stale Gemini/GPT wording is gone.

**Dependencies:** None (documents the shipped v01–v05.02 system).

**Expected result:** following the README from a clean checkout, a newcomer sets up the project and
runs human-vs-agent, agent-vs-agent, and observe; the UI presents the arena cleanly (already shipped).

**Acceptance criteria:**
- [ ] `README.md` covers setup, all three run modes (with the real commands), the protocol summary, testing, and data/reset; links the specs; no stale vendor names.
- [ ] `.env.example` exists with the `ANTHROPIC_API_KEY` placeholder and is tracked by git (`.env` stays ignored).

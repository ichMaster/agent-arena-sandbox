## v05.03 — Polish & docs

### ARENA-111 — README.md: setup, the three run modes, protocol summary, testing

**Description:**
The newcomer-facing document the roadmap names as this phase's DoD: setup, all three run modes
(human-vs-agent, agent-vs-agent, observe), a WS protocol summary, and how to run the tests — with
links out to `spec/game_specification.md` and `spec/architecture.md` for the full detail rather
than duplicating it. Touches: `README.md` (new).

**What needs to be done:**
- **Setup:** `python3 -m venv .venv && .venv/bin/pip install -e ".[dev]"`; `ANTHROPIC_API_KEY` in
  a gitignored `.env` (required only for a live agent run, never for the default test suite);
  note `./arena.db` is SQLite, gitignored, and resettable by deleting the file.
- **Run mode 1 (human-vs-agent):** start the server (`uvicorn server.main:app`), open `/ui`, Host
  a match, run `python3 -m agent.agent --match-id <id> --profile profiles/aggressive.yml` in
  another terminal.
- **Run mode 2 (agent-vs-agent):** `./scripts/run_arena.sh` (server already running) — prints the
  Observe link + match id, tails both agents' banter.
- **Run mode 3 (observe):** open `/ui`, click Observe, paste a match id — board + chat update
  live, no seat claimed.
- **WS protocol summary:** the event/action envelope shapes and the five server events / two
  client actions (architecture.md §6.2) — a short table, not the full spec; link to
  `architecture.md` for the complete contract.
- **Testing:** `pytest`, `mypy games server agent`; note the suite is free/deterministic (LLM
  mocked by default) and a live run is opt-in.
- **Links:** `spec/game_specification.md` (product vision), `spec/architecture.md` (full technical
  contract) — the source of truth this README summarizes, never duplicates at length.

**Dependencies:** None

**Expected result:**
A newcomer reading only `README.md` can set up the project and understand what each of the three
run modes does and how to try each one.

**Acceptance criteria:**
- [ ] All three run modes documented with the exact commands.
- [ ] Setup section covers `.venv`, `pip install -e ".[dev]"`, `.env`/`ANTHROPIC_API_KEY`,
      `./arena.db`.
- [ ] WS protocol summarized (not fully duplicated) with a link to `architecture.md`.
- [ ] Testing section documents `pytest`/`mypy` and the mocked-by-default LLM policy.
- [ ] Links to `spec/game_specification.md` and `spec/architecture.md`.
- [ ] Ties to phase DoD: "a README that walks through the three run modes... plus setup."

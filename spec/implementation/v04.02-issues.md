## v04.02 — Arena orchestration script

### ARENA-106 — `scripts/run_arena.sh`: ordered launch, Observe link, log tail, clean shutdown

**Description:**
The one-command demo: create a match, launch two agents with a connection order that guarantees
distinct seats, print the human's Observe instructions, tail both agents' logs live, and shut down
cleanly on Ctrl-C. Touches: `scripts/`.

**What needs to be done:**
- Health-check `$SERVER_URL` (default `http://127.0.0.1:8000`) before doing anything else -- a
  clear "server not reachable, start it with `uvicorn server.main:app`" error beats a bare `curl`
  failure under `set -euo pipefail`.
- `POST /api/v1/lobby/match` to create the match; parse `match_id` from the JSON response.
- Launch agent 1 (`python3 -m agent.agent --match-id <id> --profile <profile-1> --server-url
  <url>`) with its stdout/stderr redirected to a log file; **poll that log for its own `"joined
  as"` line (with a bounded timeout, not an infinite loop) before launching agent 2** -- this is
  the actual mechanism that makes seat assignment deterministic (see this file's reconciliation
  note: there is no `--symbol` flag; connection order is the only lever). If agent 1's process
  dies before joining, print its log and exit non-zero rather than launching agent 2 into a
  broken match.
- Launch agent 2 the same way, its own log file, no wait needed after (nothing downstream depends
  on its join beyond the match itself proceeding).
- Default the two profiles to `profiles/aggressive.yml` and `profiles/cautious.yml` (v04.01's
  contrasting pair) but accept overrides as the first two positional args.
- Print the **Observe** instructions clearly -- the match id and the literal instruction to use
  **Observe**, never Join (Join would claim one of the two seats the agents need).
- `tail -f` both agent log files so the human watching the terminal sees the same banter the
  Observe view renders.
- Clean shutdown on Ctrl-C (`trap ... INT TERM EXIT`): kill both agent processes, wait for them,
  remove the temp log files.

**Dependencies:** None

**Expected result:**
`./scripts/run_arena.sh` (with a server already running) starts a full agent-vs-agent match,
prints an Observe link/match id, and streams both agents' banter to the terminal until the game
ends or the user interrupts it.

**Acceptance criteria:**
- [ ] Fails clearly (not a bare curl error) if the server isn't reachable.
- [ ] Creates a match via the real lobby endpoint and parses its `match_id`.
- [ ] Launches agent 1, waits (bounded, not unbounded) for its own join confirmation, only then
      launches agent 2 -- the actual ordering guarantee, not a `--symbol` flag that doesn't exist.
- [ ] Exits non-zero with agent 1's log printed if agent 1 dies before joining.
- [ ] Defaults to the two v04.01 personas; both real profile paths are referenced.
- [ ] Prints the match id and instructs the human to **Observe**, not Join.
- [ ] Tails both agents' logs live; cleans up processes and temp files on Ctrl-C.
- [ ] **Script test:** `bash -n` syntax check; content checks confirming the lobby endpoint, both
      profile paths, the join-then-launch ordering (agent 1's wait logic appears before agent 2's
      launch in the script source), and "Observe" (not "Join") in the printed instructions.
- [ ] Ties to phase DoD (v04 release gate): starts a full match; a human at `/ui` → Observe with
      the printed id watches the whole game and banter to `game_over`; the two agents reliably get
      distinct seats.

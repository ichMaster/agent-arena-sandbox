## v04.02 — Arena orchestration script

### ARENA-OPUS-033 — `scripts/run_arena.sh` — launch an agent-vs-agent match (v04 gate)

**Description:** a bash script that creates a match, launches the two persona agents in the correct
order (no seat race, deterministic X/O), prints the **Observe** link + match id, and tails both agents'
logs until Ctrl-C (architecture §12 mode 2). Touches: `scripts/run_arena.sh`, `tests/`.

**What needs to be done:**
- `scripts/run_arena.sh` (`#!/usr/bin/env bash`, `set -euo pipefail`, executable):
  - `cd` to the repo root (`dirname "$0"/..`) so `.env` / `profiles/` / `agent/` resolve.
  - Pick the interpreter: `PYTHON=${PYTHON:-.venv/bin/python}`, fall back to `python3` if absent.
  - `SERVER_URL=${SERVER_URL:-http://127.0.0.1:8000}`; profiles as args
    (`${1:-profiles/aggressive.yml}` X, `${2:-profiles/cautious.yml}` O).
  - **Create the match:** `curl -sf -X POST "$SERVER_URL/api/v1/lobby/match"`, extract `match_id`
    (via `$PYTHON -c` JSON — no `jq` dependency).
  - **Print the watch instructions:** the full match id + "open `$SERVER_URL/ui` → **Observe** → paste
    the id" with an explicit "use **Observe**, not **Join** (Join steals a player seat)".
  - **Launch in order:** start agent 1 (X profile) → its stdout to a temp log; **wait until its log
    shows `joined as`** (with a liveness check that it didn't exit early) → then start agent 2 (O
    profile). This guarantees agent 1 = X, agent 2 = O.
  - `trap` cleanup that kills both agent PIDs on `INT`/`TERM`/`EXIT`; `tail -f` both logs until Ctrl-C.
- **Test** (`tests/test_run_arena_script.py`): static script checks (do **not** execute it — that needs
  a live server + paid calls): `bash -n` parses clean; references **both** real profiles and
  `/api/v1/lobby/match`; waits for the first agent's `joined` line **before** launching the second;
  instructs **Observe** and warns against **Join**; invokes `agent/agent.py`.

**Dependencies:** None (composes v04.01 profiles + v02.03 agent CLI + v03.03 observer).

**Expected result:** `./scripts/run_arena.sh` (server already running) starts a full agent-vs-agent
match; opening `/ui` → **Observe** with the printed id watches the whole game + banter to `game_over`.

**Acceptance criteria:**
- [ ] `scripts/run_arena.sh` is executable, valid bash (`bash -n` clean), and runs from the repo root.
- [ ] Creates a match via `POST /lobby/match`, launches both persona agents **in order** (waits for agent 1's `joined` before agent 2 → deterministic X/O), prints the full match id + the **Observe** instruction, and cleans up both processes on exit.
- [ ] The script tells the human to **Observe**, never **Join**.
- [ ] **Test:** `bash -n` passes; the script references both profiles, the lobby endpoint, the wait-for-first-agent ordering, the Observe (not Join) guidance, and `agent/agent.py`. No server started, no paid call.
- [ ] Ties to DoD (v04 gate): one command starts a watchable agent-vs-agent match; the two agents reliably get distinct seats.

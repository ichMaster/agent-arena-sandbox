agent talks to a model — with its single real implementation, **`AnthropicHaikuClient`** (Anthropic

patched, so **no test spends a single token**. Depends on: v01 (the released project skeleton only).

## v02.01 — `LLMClient` seam & the Anthropic Haiku client

### ARENA-OPUS-SONNET-016 — `AgentResponse` schema + the `LLMClient` seam (contract)

**Description:**
The vendor seam gate — `agent/schemas.py` (`AgentResponse`) and `agent/llm.py` (the abstract
**`LLMClient`**, generic over a `BaseModel` schema). This **pins the §4.2 `LLMClient` seam** and the
§7.3 `AgentResponse` schema. Touches: `agent/schemas.py`, `agent/llm.py`, `tests/`.

**What needs to be done:**
- `agent/schemas.py`: `class AgentResponse(BaseModel)` with `move: int` and `comment: str` (§7.3).
- `agent/llm.py`: `T = TypeVar("T", bound=BaseModel)` and `class LLMClient(ABC)` with the single abstract method `async def generate_structured_response(self, prompt: str, schema: type[T]) -> T` (§4.2). Document the seam rules: structured output is forced at the client and returned validated; the caller never parses raw text; the seam is **vendor-agnostic** and imports nothing from `server/`.
- No concrete client and no SDK dependency yet (those land in ARENA-OPUS-SONNET-017).

**Dependencies:** None (v02.01 depends on v01, already released).

**Expected result:**
An importable, strictly-typed `LLMClient` abstraction and the `AgentResponse` schema, both pinned by a contract test.

**Acceptance criteria:**
- [ ] `agent/schemas.py` defines `AgentResponse{move: int, comment: str}`; `agent/llm.py` defines `LLMClient(ABC)` with the one generic `async` method per §4.2; neither imports from `server/`.
- [ ] **Contract test:** the `LLMClient` seam — method name + signature (`generate_structured_response(prompt: str, schema: type[T]) -> T`, async, generic) — and the `AgentResponse` field shape are pinned (§4.2/§7.3). *(Implemented as documented — no architecture change.)*
- [ ] **Unit test:** `AgentResponse` validates a well-formed `{move, comment}` and rejects a malformed one; the abstract `LLMClient` cannot be instantiated. **No LLM, no paid call.**
- [ ] mypy (strict) clean on `agent/schemas.py` and `agent/llm.py`.
- [ ] Ties to DoD: the seam the agent references and the validated structure the model must return.

### ARENA-OPUS-SONNET-017 — `AnthropicHaikuClient` — Haiku via the SDK, structured output (mocked)

**Description:**
The single concrete `LLMClient`: **`AnthropicHaikuClient`** (Anthropic Haiku), which forces structured
output at the client and returns a validated `AgentResponse`. The Anthropic SDK is **always mocked in
tests**. Touches: `agent/llm.py`, `pyproject.toml` (add the `anthropic` runtime dep), `tests/`.

**What needs to be done:**
- `agent/llm.py`: `class AnthropicHaikuClient(LLMClient)` using the Anthropic SDK's **async** client (`AsyncAnthropic`). `generate_structured_response(prompt, schema)` forces structured output (the recommended path is `messages.parse(..., output_format=schema)` → the validated `.parsed_output`; a `tool-use`/JSON-schema path is equally acceptable) and returns the `schema` instance — the caller never parses raw text.
- A single **model-id config constant** for Haiku: `claude-haiku-4-5` (confirm against the live model list, e.g. via the Models API / the claude-api reference, rather than hardcoding a guess). Pass `temperature` through to the request (Haiku accepts sampling params).
- Add `anthropic` to `pyproject.toml` runtime dependencies.

**Dependencies:** ARENA-OPUS-SONNET-016

**Expected result:**
`AnthropicHaikuClient.generate_structured_response(...)` returns a validated `AgentResponse` from a mocked SDK, with no raw-text parsing in the caller.

**Acceptance criteria:**
- [ ] `AnthropicHaikuClient` implements `LLMClient` via the async Anthropic SDK, forcing structured output validated into the passed schema; the Haiku model id is a single constant (`claude-haiku-4-5`).
- [ ] **Unit test (SDK mocked — no paid call):** the client returns a parsed `AgentResponse` from a **patched** Anthropic client; **malformed model output surfaces as a validation error** (not silently accepted). The test asserts **no network / no real SDK call** is made.
- [ ] mypy (strict) clean on `agent/llm.py`.
- [ ] Ties to DoD: the client whose `generate_structured_response` yields a validated `AgentResponse`.

### ARENA-OPUS-SONNET-018 — `create_llm_client` dispatch + fail-fast API-key handling

**Description:**
The config-driven factory `create_llm_client(model_type, api_key, temperature)` (§4.2) so
`agent/agent.py` never imports a concrete client, plus **fail-fast** `ANTHROPIC_API_KEY` handling —
the secret lives only in the agent process (§9). Touches: `agent/llm.py`, `tests/`.

**What needs to be done:**
- `agent/llm.py`: `create_llm_client(model_type: str, api_key: str, temperature: float) -> LLMClient` dispatching on `model_type` (`"haiku"` → `AnthropicHaikuClient`); an unknown `model_type` raises a clear error.
- Fail-fast key: a helper that reads `ANTHROPIC_API_KEY` from the environment and **aborts with a clear message if it is missing/empty**, and/or `create_llm_client` rejects an empty `api_key`. The key is never logged.
- Keep `agent/agent.py` (later) able to construct a client via the factory alone — no concrete-client import.

**Dependencies:** ARENA-OPUS-SONNET-016, ARENA-OPUS-SONNET-017

**Expected result:**
`create_llm_client("haiku", key, temp)` returns an `AnthropicHaikuClient`; a missing API key aborts with a clear message; an unknown model type raises.

**Acceptance criteria:**
- [ ] `create_llm_client("haiku", …)` returns an `AnthropicHaikuClient` (an `LLMClient`); an unknown `model_type` raises a clear error.
- [ ] A missing/empty `ANTHROPIC_API_KEY` aborts with a clear message; the key is never logged.
- [ ] **Unit test (no paid call):** dispatch returns the right client for `"haiku"` and raises for an unknown type; the missing-key path aborts with a clear error. The mocked SDK confirms no real client is constructed against the network.
- [ ] mypy (strict) clean on the factory + key helper.
- [ ] Ties to DoD: the agent references only the seam; a missing key aborts startup clearly.

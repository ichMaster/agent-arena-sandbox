## Detailed Results

### ARENA-009 — `IssuedToken`, token issue & validation
`secrets.token_urlsafe(32)`, a frozen `IssuedToken`, and `validate_token` returning `None` rather
than raising — at WS connect that becomes a 4001 close, not a traceback. Uniqueness asserted over
2000 tokens; no player-supplied text recoverable from a token.

### ARENA-010 — Lobby request/response schemas
`JoinRequest` + the three response models. Two choices carry weight and are tested as such:
`spectator` defaults to `False`, and `extra="forbid"` means a typo'd `spectatr` is **refused**
rather than accepted-and-ignored — which would have seated someone who asked to observe.

`pydantic` declared as a runtime dependency rather than left hand-installed.

### ARENA-011 — FastAPI app, lifespan & the lobby endpoints
Lifespan (not `@app.on_event` — a test greps the source so it cannot be reintroduced), health,
create, join. 404 on an unknown match, with a further test that a 404 join writes **no** participant
row.

The §6.3 ordering rule is asserted at the row: after a spectator join, `is_spectator` is set while
`symbol` is still `NULL`. That is what makes "an observer can never be handed a seat" true by
construction rather than by every later seating path remembering to check.

**v01.02 review finding #5 resolved:** `session_scope()` is adopted, not deleted — `get_session`
delegates to it.

**Verified beyond the suite:** the app was booted under real `uvicorn` and exercised over HTTP
(health, create, join). `TestClient` alone would not catch a lifespan that only works in-process.

### ARENA-012 — `server/match.py` — seat & turn helpers
`claim_seat` / `release_seat` / `match_view`, each taking a session. The seat rule is now proven
**through REST** — real joins, real tokens — including two joins both named `"Human"`, which is the
shape the rule meets in production because the UI names everyone that.

Two structural guards: a test parses the module's AST and fails on any module-level
dict/list/set, so "reconstruct, don't cache" cannot be quietly reversed; and every helper is
asserted to take `session` first, so none can acquire its own connection.

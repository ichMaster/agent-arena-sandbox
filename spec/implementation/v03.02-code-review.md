## Finding 1 — the phase boundary leaked

v03.01 was scoped to the shell and connection, but the `app.js` written there already
contained `renderBoard`, `handleCellClick`, `handleGameOver`, `renderChat` and
`spectateMatch` — the v03.02 and v03.03 surface. So v03.02 added only the tests that pin
those behaviours.

This is worth recording rather than smoothing over, because **it makes the per-version
timing and diff-size figures in the tracking misleading**: v03.01 carries code that the
roadmap assigns to two later versions, and v03.02 looks artificially cheap. The generated
code is correct and fully tested; the *record* of when it arrived is not, and this run
exists to measure exactly that.

No code change — reverting and re-splitting a working, tested file would corrupt the
history further rather than repair it.

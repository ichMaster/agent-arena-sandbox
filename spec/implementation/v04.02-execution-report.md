## Detailed Results

### ARENA-106: scripts/run_arena.sh
**Status:** completed · **Commit:** ba9941b
**Validation:** [x] tests (217 full suite) · [x] mypy --strict · [x] bash -n · [x] 3x live end-to-end runs

**Found and fixed during live validation** (a real server, two real agents, a real Anthropic API
key -- the one intentionally-live path in this project, per architecture.md §12):
1. Bare `python3` fails on an unactivated shell (no project deps installed) -- now prefers
   `.venv/bin/python3` when present.
2. `tail -f` as the final foreground command means bash defers the EXIT/TERM trap until it
   returns, which never happens on its own -- a non-interactive `kill` of the script's own PID
   hung forever. Fixed by backgrounding `tail -f` and `wait`ing on it.
3. The trap fires cleanup() on both the signal and the subsequent natural EXIT, double-printing
   "Shutting down agents..." -- added a run-once guard.

All three fixes were verified live: a full agent-vs-agent game played to completion (Aggressor's
taunts vs Sentinel's wary banter landed exactly as v04.01 designed), then two further runs
specifically exercising the direct-kill shutdown path, both clean with no leaked processes and no
duplicate output.

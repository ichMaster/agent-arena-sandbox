## v05.02 — End-to-end integration suite

### ARENA-110 — Agent-vs-agent end-to-end: two real AgentSessions, mocked LLM, full game

**Description:**
Two real `agent.agent.AgentSession` instances (not a raw WS client standing in for one side),
each with its own `ScriptedLLMClient`, play a full game to `game_over` over a real live server —
mirroring what `scripts/run_arena.sh` does in production, but deterministic, free, and part of the
default CI-safe suite. Touches: `tests/`.

**What needs to be done:**
- New test: create a match, connect agent session 1 (claims X — the same seat-ordering discipline
  `test_agent_live_game.py` already established: claim the seat and let it commit before the
  second session connects, then start draining events only once both are positioned to receive
  each other's broadcasts).
- Connect agent session 2 (claims O) the same way.
- Script both sides' `ScriptedLLMClient` to a short, deterministic, legal game reaching
  `game_over` (e.g. X wins a row) — no live model call for either side.
- Drive both sessions' event loops concurrently (`asyncio.gather` or two background tasks) until
  both exit cleanly on `game_over`.
- Assert: the game reaches a real terminal result; both sessions' own `MemoryWindow`s recorded
  both sides' moves and chat; neither session raised.

**Dependencies:** None

**Expected result:**
Two independent `AgentSession`s, wired only through the real server (no direct coupling between
them), play a complete game and both exit cleanly — with zero real network calls to Anthropic.

**Acceptance criteria:**
- [ ] Two real `AgentSession` instances (`agent.agent.AgentSession`), each `ScriptedLLMClient`-backed.
- [ ] Full game reaches `game_over` over a real live server connection.
- [ ] Both sessions' run loops exit cleanly with no exception.
- [ ] Zero real Anthropic API calls (confirmed by construction: only `ScriptedLLMClient` is used).
- [ ] Ties to phase DoD: "the suite runs a full match over real connections and passes
      deterministically and free."

## v05.02 — End-to-end integration suite

### ARENA-OPUS-035 — Global no-paid-call guard (autouse) + guard test

**Description:** guarantee **no test path can reach the Anthropic API** (§11: the LLM stays mocked
throughout). Add an autouse fixture in `conftest.py` that patches `agent.llm.AsyncAnthropic` to a
dummy for every test, so even an un-mocked `create_llm_client` cannot open a network client. Touches:
`tests/conftest.py`, `tests/`.

**What needs to be done:**
- `conftest.py`: an `autouse=True` fixture wrapping every test with
  `patch("agent.llm.AsyncAnthropic", <MagicMock factory>)` — tests that patch it themselves still
  override locally (nested patch); tests that don't are now safe by default.
- A test (`tests/test_no_paid_call_guard.py`) proving the guard is active: within a test,
  `create_llm_client("haiku", "sk-fake", 0.5)` builds an `AnthropicHaikuClient` whose underlying
  client is the patched dummy (no real `AsyncAnthropic`), and no network is touched.

**Dependencies:** None.

**Expected result:** the whole suite is paid-call-safe by construction; a regression that forgets to
mock the SDK still can't hit the network.

**Acceptance criteria:**
- [ ] An autouse `conftest.py` fixture patches `agent.llm.AsyncAnthropic` for every test.
- [ ] Existing LLM tests still pass (their local patches override the guard).
- [ ] **Guard test:** an un-mocked `create_llm_client(...)` inside a test yields a client backed by the dummy, not the real SDK. No paid call.
- [ ] mypy (strict) clean. Ties to DoD: the suite is deterministic and **free** — no paid model call anywhere.

### ARENA-OPUS-036 — Agent-vs-agent end-to-end over the real server

**Description:** two real `AgentSession`s (the Ironclaw + Bastion personas, both LLMs **mocked** with a
scripted deterministic game) play each other to `game_over` through the **real server** over real WS
connections (§11) — the v04 headline scenario, as an automated integration test. Touches: `tests/`.

**What needs to be done:**
- `tests/test_agent_vs_agent.py`: create a match; join two players; open two `TestClient` WebSockets;
  build an `AgentSession` per side from `profiles/aggressive.yml` (X, Ironclaw) and
  `profiles/cautious.yml` (O, Bastion),
  each with a scripted mock `LLMClient` producing a fixed line (X: 0,1,2 → top-row win; O: 3,4).
- A lock-step driver that, after the two `joined` events, delivers each server broadcast to **both**
  sockets/sessions in order (both receive the same broadcast stream), sending whatever actions each
  session returns, until `game_over`.
- Assert: the game reaches `game_over` with `result == "X"`; each side acted **only on its turn**;
  the mock LLMs were called exactly the scripted number of times (proving no action on the terminal
  update); opponent moves/chat were recorded in each side's memory. **Zero paid calls.**

**Dependencies:** ARENA-OPUS-035.

**Expected result:** an automated agent-vs-agent match runs end to end over real connections and
passes deterministically and free.

**Acceptance criteria:**
- [ ] Two `AgentSession`s play a full game to `game_over` (`result == "X"`) through the real server.
- [ ] Each session acts only on its own turn; LLM call counts match the script (no act on the terminal `state_update`).
- [ ] Deterministic across repeated runs; **no paid call** (both LLMs mocked, enforced by the #035 guard too).
- [ ] mypy (strict) clean. Ties to DoD: a full match over real connections, agent-vs-agent path covered.

## What's solid
The autouse guard (`tests/conftest.py`) patches `agent.llm.AsyncAnthropic` at the exact same import
path every existing test already patches locally, so it composes rather than conflicts. The
agent-vs-agent driver (`test_agent_vs_agent.py`) reads one broadcast event at a time from both sockets
and asserts `event_x == event_o` at every step — this is itself a runtime check that the two
connections see an identical broadcast stream, not just an assumption baked into the test's shape; it
passed deterministically across 4 repeated runs. LLM call counts are asserted exactly (3 for X, 2 for
O), which is the concrete proof that neither session acted on the terminal `state_update` (whose
`current_turn` is `null`) or on `game_over` — the same discipline `test_agent_session.py` established
for the single-agent case, now proven symmetrically for two.

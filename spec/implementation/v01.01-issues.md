### ARENA-038 — TicTacToe engine — board, turn order & move legality

**Description:**
`games/tictactoe.py`: the concrete `TicTacToe(GameInterface)` — a 9-cell board (list of
`None | "X" | "O"`), `X` moves first, and legality-only `apply_move` (§4.1: the sole legality
authority, never raises on bad input). Win/draw detection is ARENA-039; this issue lands the board
state, turn alternation, and move validation. Touches: `games/`.

**What needs to be done:**
- `TicTacToe.__init__`: 9-cell board, `current_player = "X"`.
- `get_state() -> dict[str, Any]`: `{"board": [...], "current_player": ...}`.
- `get_valid_moves() -> list[int]`: indices `0-8` of empty cells.
- `apply_move(self, player: str, move: Any) -> bool`: rejects (returns `False`, never raises)
  out-of-range (`< 0` or `> 8`), non-`int` move payloads, occupied cells, and a `player` who isn't
  `current_player`; on success places the mark and flips `current_player`.
- The move payload stays opaque outside this module (§4.1) — no cell-index assumptions leak into
  `games/interface.py`.

**Dependencies:** ARENA-037

**Expected result:**
A `TicTacToe` instance correctly tracks whose turn it is, accepts only legal moves, and never
raises on malformed input.

**Acceptance criteria:**
- [ ] **Unit test:** legal move updates the board and flips the turn; illegal moves (out-of-range,
  occupied, wrong type, wrong player) are rejected via a `False` return, not an exception.
- [ ] **Unit test:** `get_valid_moves()` shrinks by exactly one index per legal move and never
  includes an occupied cell.
- [ ] `mypy games` strict-clean.
- [ ] Ties to v01.01 DoD: applies legal moves, rejects illegal ones without raising.

### ARENA-039 — Terminal detection — 8 win lines, draw, is_game_over

**Description:**
Complete the engine with `is_game_over() -> str | None` (§4.1: `"X" | "O" | "draw" | None`) —
checks all 8 winning lines (3 rows, 3 columns, 2 diagonals) and a full-board no-winner draw — plus
the exhaustive unit suite the phase DoD requires. Touches: `games/`, `tests/`.

**What needs to be done:**
- `is_game_over()`: iterate the 8 winning lines, return the winning symbol if any line is
  3-in-a-row of the same non-`None` mark; return `"draw"` if the board is full with no winner;
  `None` while the game is ongoing.
- Exhaustive unit tests: a win on **each** of the 8 lines individually, a full-board draw, and that
  `is_game_over()` stays `None` mid-game.
- Full-suite pass over `games/`: win/loss/draw, illegal-move rejection (all three cases from
  ARENA-038), `get_valid_moves` shrinkage — the phase's complete DoD in one green run.

**Dependencies:** ARENA-038

**Expected result:**
`TicTacToe` fully satisfies `GameInterface`; win/draw/ongoing are correctly reported for all 8
lines and the full-board case, verified in isolation with no server involved.

**Acceptance criteria:**
- [ ] **Unit test:** each of the 8 winning lines independently produces the correct winner symbol.
- [ ] **Unit test:** a filled board with no line produces `"draw"`; an in-progress board produces `None`.
- [ ] **Contract test (from ARENA-037):** `GameInterface` signatures still pinned and green.
- [ ] `pytest` green and `mypy games` strict-clean for the whole `games/` package.
- [ ] Ties to v01.01 DoD (release gate): the TicTacToe engine correctly reports valid moves,
  applies legal moves, rejects illegal ones without raising, and detects win/loss/draw — verified
  in isolation.

The Agent Designer config (§7.2, spec §5.2): `agent/profile.py` with a strictly-typed

### ARENA-OPUS-SONNET-020 — `MemoryWindow` — rolling recent moves + chat

**Description:**
The agent's short-term memory (§7.2): a bounded window of recent match events (moves + chat) the
prompt embeds; oldest events evicted first. Touches: `agent/memory.py`, `tests/`.

**What needs to be done:**
- `agent/memory.py`: `MemoryWindow(limit)` over `deque(maxlen=limit)`; `record_move(player, move)`
  and `record_chat(sender, message)` rendering short event lines; `events() -> list[str]` (a copy);
  `__len__`; a non-positive limit raises.
- Pure logic — imports nothing from `server/`, no I/O.

**Dependencies:** None.

**Expected result:**
A window that keeps exactly the last *N* events in order, evicting the oldest, ready for prompt embedding.

**Acceptance criteria:**
- [ ] Events beyond `limit` evict the oldest; order is oldest→newest; moves and chat mix correctly.
- [ ] **Unit test:** windowing/eviction, ordering, mixed events, `len`, `events()` returns a copy, invalid limit raises. No LLM, no paid call.
- [ ] mypy (strict) clean on `agent/memory.py`.
- [ ] Ties to DoD: the memory window keeps the last *N* events.

### ARENA-OPUS-SONNET-021 — `build_prompt` — persona + memory + board → one prompt

**Description:**
The prompt builder (§7.2): compose persona + the memory window + the **pushed** board/valid-moves
into one decision prompt whose reply contract matches `AgentResponse{move, comment}`. Because the
server pushes full turn state (v01.04), the agent never round-trips to read state. Touches:
`agent/prompt.py`, `tests/`.

**What needs to be done:**
- `agent/prompt.py`: `build_prompt(memory, board, valid_moves, persona) -> str` (roadmap signature) —
  renders the persona, the recent-events list (with an explicit "nothing yet" for an empty window),
  the 3×3 board (empty cells shown as their index so the model can name a cell), the legal moves, and
  the instruction to answer with one `move` from the legal list + a short in-character `comment`.
- Deterministic, pure string composition — no model call here.

**Dependencies:** ARENA-OPUS-SONNET-019, ARENA-OPUS-SONNET-020

**Expected result:**
A persona-driven prompt embedding the current board and exactly the legal moves, ready for
`LLMClient.generate_structured_response(prompt, AgentResponse)`.

**Acceptance criteria:**
- [ ] The prompt contains the persona text, every board mark, **all and only** the legal moves, and the recorded memory events; an empty window renders a clear placeholder.
- [ ] **Unit test:** persona/board/valid-moves/memory presence; occupied cells not offered as moves; empty-memory case. No LLM, no paid call.
- [ ] mypy (strict) clean on `agent/prompt.py`.
- [ ] Ties to DoD: the prompt builder produces a persona-driven prompt embedding the board and legal moves.

- **`tests/conftest.py`** (new — the suite's first shared fixture file): an autouse fixture patches
  `agent.llm.AsyncAnthropic` for every test, so a regression that forgets a local mock still can't
  reach the network. Existing local `patch(...)` calls override it correctly (standard nested-patch
  behavior) — confirmed no test broke.
- **`tests/test_agent_vs_agent.py`**: two real `AgentSession`s (Ironclaw vs Bastion, both LLMs scripted)
  play a full game to `game_over` over real WS connections against the real server — the v04 headline
  scenario as an automated test. An event-by-event lock-step driver (not paired chat/state_update
  reads) delivers each broadcast symmetrically to both sessions; each acts only on its own turn.
  Asserts the exact LLM call count per side (no action on the terminal update), the win, and that each
  side's memory records only the opponent's moves.

`issue.commit`/`issue.closed`/`issue.uploaded`/`issue.implement.end`/`issue.validate.end`
emitted since ARENA-071 used the wrong `tracker.emit` data shape and was silently dropped
(the emitter never raises by design). Backfilled the missing events for ARENA-071..083 with
correct data reconstructed from real commits/GitHub issue numbers, corrected 2
`finding.classified` events (wrong enum case) and a malformed `run.estimate` event (whose
bad shape was crashing the dashboard's reducer entirely). All `tracker.emit` calls from
ARENA-084 onward use the corrected shapes.

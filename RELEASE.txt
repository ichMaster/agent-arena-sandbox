AgentArena — Release Notes
===========================

Version 02.03.00 (2026-08-04) — v02 release gate
------------------------------
- agent/agent.py: the CLI entrypoint — arg parsing, AgentSession,
  join_match over REST, the WS event loop (join, connect, dispatch,
  act only on its own turn, memory recording without self-echo
  duplication), decide_move (retry then random legal fallback),
  line-buffered output, a direct-run shim.
- Verified end-to-end against a real running server: a full game,
  including a genuinely-exercised illegal-move retry, reaching
  game_over with a clean process exit.
- Code review fix: server/main.py's WS handler no longer logs a full
  unhandled-exception traceback on every normal game completion
  (close_room's own disconnect of the winning mover's socket was
  previously propagating as an unhandled WebSocketDisconnect).
- 137 tests passing, mypy --strict clean across games/server/agent.
  No live model call anywhere in the default suite.
- v02 — Agent Client (Haiku) — is now complete: the LLMClient seam,
  persona/memory/prompt, and the full agent event loop playing real
  games end-to-end.

Version 02.02.00 (2026-08-04)

- MemoryWindow: a bounded rolling record of recent moves and chat,
  eviction verified against a mixed sequence of both (ARENA-056).

  memory history into one prompt string — no I/O, no model call
  (ARENA-057).
- Code review: no fix-now findings this phase (a low-risk phase — YAML
  parsing, a deque, string assembly); one LOW finding deferred
  alongside v01.01's analogous encapsulation note.
- 123 tests passing, mypy --strict clean across games/server/agent.

Version 01.04.00 (2026-08-04) — v01 release gate
------------------------------
- ConnectionManager: connect/disconnect/broadcast/send_to/close_room,
  broadcast prunes a dead socket without aborting delivery to the rest
  (ARENA-048).
- The WS endpoint: GET /ws/match/{match_id}?token= — bad/foreign token
  closes 4001; a valid token connects and receives joined; cleanup
  (seat release) runs in a finally block shielded against an anyio
  CancelScope cancellation, not just asyncio's (ARENA-049).
- chat: persists + broadcasts chat_message; a malformed message yields
  an error without dropping the connection (ARENA-050).
- submit_move: the full §5.4 move-authority flow — no-seat/out-of-turn/
  illegal moves refused via error with no state mutation; a completed
  game broadcasts state_update (current_turn: null) then game_over,
  then closes the room (ARENA-051).
- Code review fix: chat messages now bounded to 500 characters
  (previously unbounded, and — unlike v01.03's player_name finding —
  actually broadcast live to every connected client).
- 99 tests passing, mypy --strict clean across games/server/agent.
- v01 — Game Core & Server Foundation — is now complete: the engine,
  persistence, lobby REST, and the full WebSocket protocol with
  server-validated move authority.

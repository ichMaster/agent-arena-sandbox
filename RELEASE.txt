AgentArena — Release Notes
===========================

Version 01.02.00 (2026-08-03)
------------------------------
- Async SQLite engine, session maker & init_models, with a connect-time
  PRAGMA foreign_keys=ON listener (ARENA-040).
- The four ORM tables (matches, participants, moves, chat_messages) with
  UNIQUE(match_id, symbol) on participants (ARENA-041).
- Repository: create_match, get_match, add_participant, assign_symbol (the
  full §5.2 seat rule, keyed by token never name), release_seat, log_move,
  log_chat (ARENA-042).
- reconstruct_game & current_turn: live state derived by replaying the move
  log through TicTacToe, verified across win/draw and a simulated process
  restart (ARENA-043).
- Code review fix: assign_symbol now retries on a concurrent seat-assignment
  conflict instead of raising IntegrityError.
- 52 tests passing, mypy --strict clean across games/server/agent.

Version 01.01.00 (2026-08-03)
------------------------------
- Repo skeleton & packaging: pyproject.toml (strict mypy, pytest config, explicit
  setuptools package list), games/server/agent package layout (ARENA-036).
- GameInterface — the abstract game plug-in seam (get_state, get_valid_moves,
  apply_move, is_game_over), pinned by a contract test (ARENA-037).
- TicTacToe engine: 9-cell board, X-first turn order, apply_move as the sole
  legality authority — rejects out-of-range/occupied/wrong-type/wrong-turn moves
  without raising (ARENA-038).
- Terminal detection: all 8 winning lines plus full-board draw (ARENA-039).
- Code review fix: apply_move now rejects further moves once the game has ended
  (previously a finished game silently kept accepting moves).
- 32 tests passing, mypy --strict clean on games/.
